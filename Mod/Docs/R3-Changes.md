# Held models R3

This independent candidate adds a view-only desert palette and 30 dedicated eye-level assets from the six existing local art chats. World ModelDefs, mesh arrays, original material objects and Workshop installs remain unchanged. Original source files and R2 receipts are preserved.

The desert switch defaults on. Near-black neutral vertex/material colours become RGB (0.78, 0.65, 0.43); wood, leather, brass, copper, cartridges, lenses and emissive regions are protected. It is deliberately scoped to external first-person models, not a repaint of all world assets.

28 iron sights use actual rear gaps/apertures and front-tip anchors. Fourteen optic templates retain the established zoom interface. Hand mortar and sightless sawed-off use explicit reticle routes. Boys uses a side-offset line. M82A2 selects a precision optic template rather than claiming authentic mechanical sights. Optical overlays do not render physical scope glass or establish ballistic zero at every distance.

The new assets are loaded by HeldWeaponVisualDef only for FPS, before automatic world-model lookup but after registered providers. File coordinates remain raw +X forward and +Y up with original grip/muzzle and scale. IsoRim's OBJ loader negates Z; R3.1 maps raw anchors and directions into that loaded coordinate system exactly once. Automatically inferred engine points and default C# provider points are already in engine coordinates. C# providers supplying raw points may opt in using rawObjCoordinates=true. Five declared minimal body exceptions in the art handoff are retained. No observationLift or second mesh reflection is applied.

Palette models use dedicated view batches with the original OBJ positions/normals and stable normal-based vertex shading, plus their own cell's ambient brightness. The material uses lightMode=0 and renderQueue=3102. Emissive batches remain separate and unshaded. The world AO setting and shared materials are not modified. Texture/beam-backed models and opt-in original outlines retain the upstream path. This is a bounded first-person rendering workaround; it does not prove a general upstream renderer defect.

Earlier colour-only runs preserved the black-to-tan and original-colour isolation checks, but surface speckling remained after normal-bearing, single-light-pass and queue-only experiments. Native5's structural PASS did not resolve the Boys side-sight coordinate mismatch or speckling; its exact binaries and receipts are preserved. Native6 used R3.1 DLL SHA256 725F384E528DEADB21BE22DFBA84829B4DD3C79E164B64EBA62C10BC231AC0B8, completed 264 checks and 37 real game captures. All 37 images were reviewed: the captured palette-model surfaces are clean and the Boys side sight is centred. See Evidence/visual-review.json and Evidence/acceptance.json for the bounded findings.

This validates automated native model selection, transformations, API coordinate contracts and static game frames. Physical keyboard/mouse handling, moving/recoil sequences, night lighting, sustained CE combat and a separate no-CE game were not tested in this round. Existing environment/upstream startup errors are recorded; this is not zero-error game acceptance. Workshop was not updated.
