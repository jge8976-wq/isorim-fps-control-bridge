# 0.8.1 载具战斗、HUD 与批量模型整合

- 鼠标前侧键（当前也可按 P）：越肩 → 驾驶员 → 车长 → 其它原生乘员席位 → 越肩。只切镜头，不移动乘员。
- 右键：进入当前武器炮镜；再按一次回到开镜前的视角。
- 鼠标后侧键：退出控制；F：实际下车；Tab：切换可操作武器；R：装填。
- B：机枪／机炮在单发、三连发、全自动间切换。非此类武器保留原生射击模式切换。
- 空膛自动使用原生弹药库存装填。主炮通常一发后装填，机枪／机炮弹匣打空后装填；不生成额外弹药。装填会清除开火请求，完成后必须松开并重新按下左键，全自动也一样。
- 装填／冷却保留实时圆环及剩余时间，原有下方长提示改成左下角状态面板。
- 六类面板：轮式车辆、坦克、特种车辆、固定翼、旋翼机、船只。显示实际部件耐久、优先列出的受损部件、燃料／电量、当前武器、弹种、装弹量、库存备弹和装填状态。手操时显示速度及乘员效率。普通 3D 选中载具也能看状态；飞机、船只仍使用原框架的飞行／航行命令。
- 炮镜内显示按当前炮口、初速、重力计算的预落轨迹、首次接触圈、距离和飞行时间。Dubs 小地图显示同一位置的落点圈，载具标记缩到约 10～12 像素。
- 预测圈表示首次碰撞／接触范围；穿甲后的最终停点、移动目标以及特殊弹丸可能改变实际结果。出地图的轨迹会提示没有地图内落点。

模型整合沿用交付网格，未再次减面或拉伸。更新了 36 个原生载具视图配置及相应炮塔改装、垫圈和残骸绑定。批量交付的 57 个新资产中，55 个接入现有定义；防空车车体 037、炮塔 060 缺少对应原生载具定义，保留文件待后续配套。

构建与静态／离线检查通过；本候选未代替玩家进行地图内驾驶、射击、界面和模型视觉验收。建议先测试 Marshal 的主炮和顶置机枪：切换视角、B 三档、打空自动装填、装好后重新点击，再对照炮镜和小地图落点。
